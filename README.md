# E-CHAT — Y2K Chatroom

A static front-end prototype inspired by early web chatroom directories and instant-messenger interfaces.

## Run
Open `index.html` in a browser.

## Current features
- Retro/Y2K chatroom directory
- Search rooms
- Create a room locally
- Enter chatrooms
- People list
- Local message sending
- Browser microphone permission test

## Next stage
For real multi-user chat and multi-user voice, add a backend/signaling service. GitHub Pages can host the front-end, but it cannot itself act as the real-time chat/voice server.
